VELMORA BEAUTY - WEBSITE COMPANY PROFILE

CARA MENJALANKAN:
1. Ekstrak file ZIP.
2. Buka folder velmora_beauty_website di Visual Studio Code.
3. Buka file index.html.
4. Jalankan dengan ekstensi Live Server (klik kanan > Open with Live Server).
   Jika tidak memakai Live Server, index.html juga bisa dibuka langsung di browser.

HALAMAN:
- index.html (Home)
- about-us.html (About Us)
- katalog.html (Katalog)
- our-product.html (Our Product)
- visi-dan-misi.html (Visi dan Misi)

STRUKTUR:
- assets/css/style.css       (seluruh desain dan responsive CSS)
- assets/js/script.js        (menu mobile dan tahun footer)
- assets/images/             (6 gambar yang diberikan)

CATATAN:
Nama produk, deskripsi, dan klaim pada website adalah contoh konten untuk proyek sekolah,
bukan informasi produk komersial atau klaim efektivitas skincare.
Semua gambar yang dikirim telah disalin ke folder assets/images dan digunakan di halaman website.
